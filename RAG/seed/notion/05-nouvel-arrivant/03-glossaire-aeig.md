# Glossaire AEIG
icon: 📖

Les sigles et expressions que tu entendras souvent chez AEIG.

| Terme | Signification |
| --- | --- |
| **AEIG** | African Education and Innovation Group |
| **AEIG Bénin** | La maison mère et siège du groupe, à Cotonou |
| **AEIG CI** | AEIG Côte d'Ivoire, la filiale d'Abidjan, détenue à 100 % |
| **Academy** | AEIG Academy, l'activité de formation |
| **Lab** | AEIG Lab, l'incubateur de startups |
| **Services** | AEIG Services, le conseil et le développement numérique |
| **Envol** | Le programme d'incubation de 6 mois d'AEIG Lab |
| **CODIR** | Comité de direction groupe, réuni chaque mardi à 10h |
| **DG** | Directeur général |
| **DAF** | Directeur administratif et financier |
| **CTO** | Directeur technique groupe |
| **Kalia RH** | Le SIRH : congés, absences, notes de frais, paie |
| **Lundi ensemble** | La réunion d'équipe du lundi, 9h – 9h45, sur site |
| **Café Direction** | Rencontre avec le DG, 1er mercredi du mois à 8h30 |
| **AEIG Talks** | Présentation d'un collaborateur, dernier jeudi du mois à 16h |
| **AEIG Quarterly** | La revue trimestrielle des résultats, en visio |
| **AEIG Hack** | Le hackathon interne de 48 h, en novembre |
| **Séminaire** | Les 3 jours de mars à Grand-Popo, tout le groupe |
| **Parrain / marraine** | Le collègue qui t'accompagne pendant 3 mois |
| **Per diem** | L'indemnité journalière de mission |
| **Helpdesk** | Le support IT, `support-it@aeig.example` |
| **Apprenants** | Les personnes formées par AEIG Academy |
| **Incubés** | Les startups accompagnées par AEIG Lab |

## Les valeurs

On parle souvent des « 5 valeurs » : **Excellence**, **Audace**, **Bienveillance**, **Impact**, **Intégrité**.

## La devise

« Apprendre, oser, transmettre. »

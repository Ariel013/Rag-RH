# Jours fériés au Bénin
icon: 🇧🇯

Les collaborateurs d'**AEIG Bénin** (Cotonou) bénéficient des jours fériés légaux béninois. Ces jours sont chômés et payés.

## Jours fériés à date fixe

| Date | Fête |
| --- | --- |
| 1er janvier | Jour de l'An |
| 10 janvier | Fête des religions endogènes (Vodun Days) |
| 1er mai | Fête du Travail |
| 1er août | Fête de l'Indépendance |
| 15 août | Assomption |
| 1er novembre | Toussaint |
| 25 décembre | Noël |

## Jours fériés à date variable

| Fête | Période |
| --- | --- |
| Lundi de Pâques | Mars ou avril |
| Ascension | 39 jours après Pâques |
| Lundi de Pentecôte | 50 jours après Pâques |
| Aïd el-Fitr (fin du Ramadan) | Selon le calendrier lunaire |
| Tabaski (Aïd el-Kébir) | Selon le calendrier lunaire |
| Maouloud (naissance du Prophète) | Selon le calendrier lunaire |

!> 💡 Les dates des fêtes musulmanes sont confirmées par les autorités quelques jours avant. La RH Groupe publie la date officielle sur Slack, dans le canal #annonces, dès qu'elle est connue.

## Règles pratiques

- Un jour férié qui tombe pendant vos congés payés **n'est pas décompté** de vos congés.
- Un jour férié qui tombe un dimanche n'est pas récupéré, sauf décision officielle du gouvernement.
- Si vous travaillez un jour férié à la demande de votre manager (événement, mission client), vous récupérez une journée.

+ Je suis en mission en Côte d'Ivoire un jour férié béninois
  Pendant une mission, ce sont les jours fériés du pays où vous travaillez qui s'appliquent. Si vous travaillez un jour férié béninois, vous récupérez la journée à votre retour.

+ Fêtes religieuses non fériées
  Pour une fête religieuse importante pour vous qui n'est pas un jour férié, vous pouvez poser un jour de congé payé avec un délai de prévenance de 48 heures.

Les jours fériés en Côte d'Ivoire sont différents : voir la page « Jours fériés en Côte d'Ivoire ».
